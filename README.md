# Sales & Revenue Dashboard

## Project Overview
This project is a Sales & Revenue Analysis Dashboard created using Microsoft Power BI. It helps analyze sales performance, revenue trends, and business insights through interactive visualizations.

## Dataset
- Global Superstore (CSV)

## Tools Used
- Microsoft Power BI
- CSV Dataset

## Features
- KPI Cards (Total Sales, Total Orders, Average Sales, Revenue)
- Sales Trend Analysis
- Top Performing Categories
- Interactive Filters and Slicers
- Business Insights Dashboard

## Dashboard Visuals
- KPI Cards
- Bar Chart
- Line Chart
- Pie Chart
- Table
- Slicers
